# ANN Lab Task 2 — Logistic Regression Classification

This project implements **Logistic Regression** on two different classification datasets: the Wine Classification dataset and the Iris Flower Classification dataset.

## Datasets

* **Wine Classification:** Predicts wine categories based on chemical properties.
* **Iris Flower Classification:** Classifies iris flowers into Setosa, Versicolor, or Virginica using sepal and petal measurements.

## Technologies Used

* Python
* Pandas and NumPy
* Scikit-learn
* Matplotlib and Seaborn
* Gradio
* Flask

## Implementation

* Data exploration and preprocessing
* Handling missing values and duplicate records
* Feature scaling using StandardScaler
* Training and testing Logistic Regression models
* Model evaluation using accuracy, precision, recall, F1-score, and confusion matrices
* Interactive prediction interfaces built with Gradio and Flask

## Objective

The objective of this lab task is to understand Logistic Regression for classification, evaluate model performance, and deploy interactive interfaces for making predictions on new data.
